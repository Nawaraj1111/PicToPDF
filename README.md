# 📄 JPEG to PDF Pro

A modern, fast, and user-friendly web application that converts multiple **JPEG/JPG images into a single PDF** directly in your browser.

No installation or server is required. All image processing happens locally, ensuring speed and privacy.

---

## 🚀 Features

* 📁 Upload multiple JPG/JPEG images
* 🖱️ Drag & Drop image upload
* 🖼️ Live image preview
* 🔢 Automatic image numbering
* 🔄 Rotate images (Left & Right)
* 🗑️ Remove unwanted images
* ↕️ Drag & Drop image reordering
* 📄 Convert multiple images into a single PDF
* 📏 Support for A4, Letter, and Legal page sizes
* 🖼️ Portrait and Landscape orientation
* ⚡ Fast client-side processing
* 🔒 100% browser-based (No image uploads to a server)


## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript (ES6)
* jsPDF
* SortableJS

## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/YOUR_USERNAME/jpeg-to-pdf-pro.git
```

Go to the project directory:

```bash
cd jpeg-to-pdf-pro
```

Open the project using your preferred editor.

Example:

```bash
code .
```

Run the application by opening **index.html** in your browser or by using a local development server such as the VS Code Live Server extension.

---

## 📖 How to Use

1. Click **Select Images** or drag and drop JPEG images.
2. Preview the uploaded images.
3. Reorder images by dragging them.
4. Rotate or delete images if needed.
5. Choose:

   * Page Size
   * Orientation
   * Image Quality
6. Click **Convert to PDF**.
7. Download your generated PDF.
